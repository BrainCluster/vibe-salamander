# Vibe Salamander

A fast, keyboard-first **dual-pane file manager** for Windows: a modern spiritual successor to
[Altap / Open Salamander](https://github.com/OpenSalamander/salamander), with a native Windows 11 look.

![Vibe Salamander with documents on the left and photo thumbnails on the right](images/hero-light.png)

Vibe Salamander is free software (GPL-3.0-or-later). Its code was written by Claude (Anthropic's AI model),
with BrainCluster guiding and testing. It is young: if something goes wrong, Help → Error Log has the details,
and a [bug report](https://github.com/BrainCluster/vibe-salamander/issues/new/choose) with that file helps most.
