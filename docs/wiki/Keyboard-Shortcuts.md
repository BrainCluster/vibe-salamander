# Keyboard shortcuts

These are the defaults (Salamander's). **Every one can be changed** in Options → Configuration → Keyboard, and
each menu item and the bottom toolbar show the current keys.

**Coming from Total Commander?** Options → Configuration → Keyboard → *Shortcuts like* → **Total Commander** switches
to its keys; they are listed [at the end of this page](#total-commander-shortcuts).

## Panels and moving around

| Keys | Action |
|---|---|
| Tab | Switch panel |
| Enter | Open the folder or file |
| Backspace / Shift+Backspace | Parent directory / root directory |
| Alt+Left / Alt+Right | Back / forward |
| Alt+F1 / Alt+F2 | Change drive (left / right panel) |
| Shift+F7 | Change directory (type a path) |
| Ctrl+. | Path from the other panel |
| Ctrl+1…9 / Ctrl+Shift+1…9 | Go to / set a hot path |
| Shift+F9 | Hot path list |
| Ctrl+B | All files of the subfolders (again: back) |
| Ctrl+Q | Quick view in the other panel |
| typing | Quick search |
| Ctrl+U | Swap panels |
| Ctrl+F11 | Maximize / restore the panel |
| Ctrl+R | Refresh |
| Ctrl+H | Show hidden and system files |
| Ctrl+F12 | Filter |
| Shift+F3 | Open the folder in Explorer |

## Views and sorting

| Keys | Action |
|---|---|
| Alt+1 … Alt+5 | Brief, Detailed, Icons, Thumbnails, Tiles |
| Ctrl+F3 / F4 / F5 / F6 | Sort by name / extension / date / size |

## Files

| Keys | Action |
|---|---|
| F2 | Rename in place |
| F3 / Alt+F3 | View / Open with |
| F4 / Shift+F4 | Edit / edit a new file |
| F5 / F6 | Copy / move or rename |
| Alt+Shift+D | Duplicate (a copy next to it, named in place) |
| Shift+F2 | Multi-rename |
| F7 | Create directory |
| F8, Del / Shift+Del | Delete (Recycle Bin) / delete permanently |
| Alt+Enter | Properties |
| Ctrl+F2 | Change attributes |
| Ctrl+F7 | Change case |
| Ctrl+P | Security |
| Alt+F5 / Alt+F6 | Pack / unpack |
| Ctrl+X / Ctrl+C / Ctrl+V | Cut / copy / paste (Windows clipboard) |
| Ctrl+Shift+L / Ctrl+S | Copy as shortcut / paste shortcut |
| Alt+Ins / Alt+Shift+Ins / Ctrl+Alt+Ins | Copy full path / name / folder path as text |

## Marking

| Keys | Action |
|---|---|
| Insert / Space | Mark the focused item |
| Ctrl+A / Ctrl+D | Select all / none |
| Num + / Num − / Num * | Select by mask / unselect by mask / invert |
| Shift+Num + / Shift+Num − | (Un)select the same extension |
| Ctrl+Shift+Num + / − | (Un)select the same name |
| Ctrl+W | Restore the previous selection |
| Alt+Up / Alt+Down | Previous / next marked item |

| Ctrl+Enter / Ctrl+Shift+Enter | Name / full path to the command line |

| Ctrl+F1 | Drive information |

## Viewer (F3)

| Keys | Action |
|---|---|
| Esc / F10 | Close |
| Ctrl+F / F7 | Find |
| F3 / Shift+F3 | Find next / previous |
| Ctrl+G | Go to a line (text) or an offset (hex) |
| W | Wrap long lines |
| Ctrl+1 … Ctrl+7 | Switch view (rendered, text, hex, …) |
| Ctrl+PgUp / Ctrl+PgDn | Previous / next file of the folder |
| ← / → , + / − or the mouse wheel, 0 , R | Pictures: previous / next, zoom, fit, rotate |
| W / M / Shift+M | Pictures: fit the width / mirror / upside down |
| F11 | Full screen (F11 or Esc: back) |
| F4 | Edit the file |

## Editor (F4)

| Keys | Action |
|---|---|
| Ctrl+S / Ctrl+Shift+S | Save / save as |
| Ctrl+F / Ctrl+H | Find / replace |
| Ctrl+G | Go to line |
| Shift+Alt+F | Format JSON / XML |
| Ctrl+Shift+V | Show or hide the preview (Markdown, HTML) |
| F1 | Command palette |
| Ctrl+F3 | View the file |
| Alt+F4 | Close (asks about unsaved changes) |

## Compare files (Ctrl+Shift+C)

| Keys | Action |
|---|---|
| F7 / Shift+F7, Alt+↓ / Alt+↑ | Next / previous difference |
| Alt+→ / Alt+← | Copy the difference to the right / left |
| Ctrl+S | Save the side you're in |
| Esc | Close (asks about unsaved changes) |

## Total Commander shortcuts

With *Shortcuts like: Total Commander* (Configuration → Keyboard). Your own changes apply on top.

| Keys | Action |
|---|---|
| F2 / Ctrl+R | Refresh |
| F3 / F4 / Shift+F4 | View / edit / edit a new file |
| F5 / F6 / F7 / F8 | Copy / move / create directory / delete |
| Shift+F5 | Duplicate (a copy in the same folder) |
| Ctrl+M | Multi-rename |
| Ctrl+B | All files of the subfolders (branch view) |
| Ctrl+Q | Quick view |
| Ctrl+D | Hot path list |
| Ctrl+Enter / Ctrl+Shift+Enter / Ctrl+P | Name / full path / folder to the command line |
| Alt+F8 | Command line history |
| Ctrl+Shift+L / Ctrl+Shift+V | Copy as shortcut / paste shortcut |
| Shift+F6 | Rename in place |
| Shift+F8, Shift+Del | Delete permanently |
| F9 | The menu bar |
| Shift+F2 | Compare directories |
| Ctrl+Shift+C | Compare files |
| Alt+F1 / Alt+F2 | Left / right drive |
| Alt+F3 | Open with |
| Alt+F5 / Alt+F9 (Alt+F6) | Pack / unpack |
| Alt+Shift+F9 | Test archive |
| Alt+F7 / Alt+Shift+F7 | Find / find duplicates |
| Ctrl+F1 / Ctrl+F2 | Brief / full (detailed) view |
| Ctrl+F3 / F4 / F5 / F6 | Sort by name / extension / date / size |
| Ctrl+F12, Ctrl+S | Filter |
| Ctrl+L | Occupied space of the selection |
| Alt+Shift+Enter | Sizes of all directories |
| Alt+Down | Folder history |
| Ctrl+\ | Root directory |
| Ctrl+Left / Ctrl+Right | Open in the other panel |
| Ctrl+U | Swap panels |
| Ctrl+F / Ctrl+N, Ctrl+Shift+F | Connect to FTP / SFTP, disconnect |
| Num + / Num − / Num * / Num / | Select / unselect by mask, invert, restore the selection |
| Ctrl+Num + / Ctrl+Num −, Ctrl+A | Select all / none |
| Alt+Num + / Alt+Num − | (Un)select the same extension |
| Insert / Space | Mark and move down / mark |

The rest is the same as with Salamander's keys (Alt+1…5 views, Ctrl+1…9 hot paths, Ctrl+X / C / V, Alt+Enter).
