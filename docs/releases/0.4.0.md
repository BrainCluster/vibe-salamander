**Vibe Salamander 0.4.0**: a Disk Map with four views, archive testing and self-extracting archives, Salamander's FTP tools, This PC like Explorer, a thumbnail size slider, menu icons and many smaller fixes.

## Download

| File | For |
|---|---|
| `VibeSalamander-0.4.0-win-x64.zip` | most PCs (Intel / AMD, 64-bit) |
| `VibeSalamander-0.4.0-win-arm64.zip` | ARM PCs (Snapdragon, Copilot+ PCs) |

Unzip anywhere and run **`VibeSalamander.exe` in the main folder**. No installation; .NET and the Windows App SDK are included.
Requires Windows 10 version 2004 or later, or Windows 11. Settings stay in `%AppData%\VibeSalamander`, so an existing
configuration carries over. Not code-signed yet: if SmartScreen warns, choose **More info → Run anyway**.

## New

**Disk Map plugin** (Commands → Disk Map, Plugins → Disk Map → Show disk map)
- What takes the space in a folder or on a drive, read in the background with live counts
- Four views: **Blocks** (the default: nested rounded panels with names and sizes), **Sunburst** (rings by depth, a color per top-level folder), **Columns** (one column per level) and **Classic** (Salamander's cushion treemap, modernised, colored by file type)
- Hover for a tip and an outline, double-click to zoom in, Backspace / the mouse's back button / Up to go up; right-click: Show in panel, Copy path, Read again; keys 1–4 switch views

**Archives**
- **Test Archive**: every file is unpacked in memory and its checksum checked (ZIP, 7z, RAR, TAR and compressed TARs, gz, bz2, xz, lz), with a result per file
- **Make Self-Extracting Archive**: a ZIP becomes an .exe that unpacks on any Windows 10 or 11, nothing to install: window title, message, target folder (%TEMP% works), a program to start afterwards, or extract without asking (`/s`, `/d:folder`)
- **Archive Comment**: show and change a ZIP's comment
- **RAR archives in several volumes** (`name.part1.rar`, … or `name.rar`, `name.r00`, …) unpack, open and test with all their volumes

**FTP / SFTP**
- Connecting shows the connection log below the server list; leaving a server asks whether to disconnect
- Plugins → FTP / SFTP: **Disconnect** (also F12 in a panel on a server), **Add bookmark**, **Show log** (commands and answers, live), **Show certificate / host key**, **Send command** (raw FTP commands, or shell commands over SSH for SFTP), **Show raw listing**

**This PC like Explorer**
- Follows the panel's view: Brief, Detailed, Icons, Thumbnails and Tiles, grouped into *Devices and drives* and *Network locations*
- Drives are named like in Explorer (*System (C:)*), tiles show a fullness bar and free / total space

**Look**
- **Thumbnail size slider** (Configuration → Appearance, and on the toolbar while a panel shows thumbnails), from 64 to 256 pixels, resizing live
- Icons in all menus; the Plugins menu shows each plugin's icon
- Configuration: **search** the settings; options moved to the pages and groups they belong to
- Font size is a choice (Default, Tiny, Medium, Large); Compact / Comfortable change the font size too

## Better

- Find and Configuration windows: the whole title row drags the window
- Plugin forms can have text boxes of several lines; plugins can draw their own pictures (used by Disk Map)
