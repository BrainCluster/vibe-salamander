**Vibe Salamander 0.8.8**: as many hot paths as you like, each with a shortcut of its own.

## Download

| File | For |
|---|---|
| `VibeSalamander-0.8.8-win-x64-setup.exe` | **the installer**, most PCs (Intel / AMD, 64-bit) |
| `VibeSalamander-0.8.8-win-arm64-setup.exe` | the installer for ARM PCs (Snapdragon, Copilot+ PCs) |
| `VibeSalamander-0.8.8-portable-win-x64.zip` / `-portable-win-arm64.zip` | **portable**: unzip anywhere, nothing installed |
| `VibeSalamander-7-Zip-plugin-0.8.8-win-x64.zip` / `-win-arm64.zip` | optional: the 7-Zip plugin |

Have 0.8.0 or later? **Help → Check for Updates → Update now** installs this one (your settings stay). Not
code-signed yet: if SmartScreen warns, choose **More info → Run anyway**.

## New

- **More hot paths** (Configuration → Hot Paths): beyond Ctrl+1…9, add as many as you like, each with a name and a
  shortcut of your own: click its box and press the keys (with Ctrl or Alt, or a function key). A shortcut that is
  already a command's, or another hot path's, is named. They are in the hot path menu (Shift+F9), with their
  shortcuts, and on the hot path bar.

## Fixed

- **SFTP's "Server identity" question** opens in front of the FTP / SFTP Connections window instead of behind it
