**Vibe Salamander 0.8.5**: arrows in the picture viewer, Photos goes through the folder, a menu for opened files, and Unpack sees an archive's root folder.

## Download

| File | For |
|---|---|
| `VibeSalamander-0.8.5-win-x64-setup.exe` | **the installer**, most PCs (Intel / AMD, 64-bit) |
| `VibeSalamander-0.8.5-win-arm64-setup.exe` | the installer for ARM PCs (Snapdragon, Copilot+ PCs) |
| `VibeSalamander-0.8.5-portable-win-x64.zip` / `-portable-win-arm64.zip` | **portable**: unzip anywhere, nothing installed |
| `VibeSalamander-7-Zip-plugin-0.8.5-win-x64.zip` / `-win-arm64.zip` | optional: the 7-Zip plugin |

Have 0.8.0 or later? **Help → Check for Updates → Update now** installs this one (your settings stay). Not
code-signed yet: if SmartScreen warns, choose **More info → Run anyway**.

## New

- **The picture viewer** has small arrows at the sides to the previous and the next picture, like Photos
- **Opened files** (Alt+F11, the button in the address bar): a click goes to the file in the panel, with the cursor
  on it; the right-click menu has **Open in panel**, **Open file**, **Open with...** and **Copy path**
- **Unpack** (Alt+F6) looks into the archive: when everything is in one folder it says "Root folder x found" and
  doesn't put it in another folder named after the archive

## Better

- **Pictures open in Photos with their folder**, so its arrows go to the next picture (also for F3 when the
  built-in viewer is off)
- **The picture viewer** no longer draws a white rectangle around the picture when going to the next one
