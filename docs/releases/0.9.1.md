**Vibe Salamander 0.9.1**: tabs in each panel, the last of Salamander's everyday features, Explorer integration,
and plugins that can view files and have settings.

| File | For |

## New

- **Tabs in each panel**, looking and working like File Explorer's.
  - **Opening:** Ctrl+Shift+T opens a new tab (Ctrl+T with Total Commander keys). Ctrl+Up opens the focused folder in a new tab,
    Ctrl+Shift+Up opens it in a new tab of the other panel, and a middle click opens it in a tab behind. The + after the last tab opens one too.
  - **Switching and closing:** Ctrl+Tab and Ctrl+Shift+Tab switch. Ctrl+Shift+W closes (Ctrl+W with Total Commander keys), and so does a middle
    click or the × that appears on a tab under the pointer.
  - **Moving:** drag tabs into a new order, or onto the other panel (Ctrl copies). Ctrl+U swaps the panels with their tabs.
  - **What each tab keeps:** its folder, sorting, view, history, marks and filter. A locked tab opens a new tab instead of
    leaving its folder.
  - **How they look:** the shown tab is one shape with the address bar, and tabs behind it are duller. Each tab has its folder's
    icon (from the chosen icon pack), and a drive's root shows its label, e.g. "System (C:)". A long name scrolls while the pointer is on it.
  - **The row:** it appears from the second tab. The arrow at the end of the drive bar (Ctrl+Down) shows or hides it, and shows how
    many tabs there are while it's hidden. Configuration → Panels → Always show the row of tabs keeps it open.
  - **What opens in a tab:** a mounted disk image opens in a new tab of the other panel, and Eject in its tab's menu unmounts it.
    A folder sent to the running Vibe Salamander also opens in a new tab.
  - **Servers:** closing the last tab on an FTP / SFTP server asks whether to disconnect.
- **Salamander's remaining everyday features:**
  - **Convert** (Ctrl+K) changes the line endings and encoding of text files.
  - **Edit with** (Ctrl+Shift+F4) picks the editor for a file.
  - **Copy network path as text** (Ctrl+Shift+Ins).
  - **Plugins → Last Command** (Ctrl+I).
  - The directory line can be hidden (Options → Show).
  - F2 and F7 work inside ZIP and TAR archives.
  - Icons show Windows' overlays (Git, OneDrive, shortcut arrows) on local disks.
- **Windows integration**, all three off by default in the installer:
  - "Open in Vibe Salamander" in Explorer's menu for folders and drives.
  - `vibesalamander` on the PATH.
  - Win+E opens Vibe Salamander instead of Explorer.
- **FTP / SFTP:**
  - The Attr column shows permissions (`rwxr-xr-x`), and the information line shows the owner and where links point.
  - The panel shows the server's free space when the server reports it.
  - Change Attributes sets permissions (`755`).
  - An interrupted copy can be **resumed**.

## For plugin authors

The plugin contracts are frozen from this release on: they only grow, so a plugin keeps loading in later versions.
`docs/plugin-api/contracts.txt` lists them, and a test guards them.

New:
- viewers for F3 (`IPluginViewer`);
- a settings page in Configuration → Plugins (`GetSettings` / `ApplySettings`);
- `MinimumHostVersion`, so an older Vibe Salamander explains instead of failing;
- permissions, owners, link targets, free space and resume for file systems.

The example plugin shows a CSV viewer and a settings page; the **Writing Plugins** wiki page covers all of it.

## Fixed

- A clicked tab changes colour at once instead of after its folder has loaded.

## Under the hood

- New UI tests mount an ISO image the test makes itself, try the installer's Windows integration (installing and
  uninstalling), and check that a folder sent to the running program opens in a new tab.
- Hovering and dragging tabs can't be simulated on GitHub's test machines; those tests run on a real desktop.
- The winget submission brings its fork of winget-pkgs up to date first (0.9.0's submission was refused for that).
