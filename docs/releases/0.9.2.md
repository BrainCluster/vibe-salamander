**Vibe Salamander 0.9.2**: a Git plugin, a Media Info plugin, and copies of a file or folder in its own folder.

## Download

| File | For |
|---|---|
| `VibeSalamander-0.9.2-win-x64-setup.exe` | **the installer**, most PCs (Intel / AMD, 64-bit) |
| `VibeSalamander-0.9.2-win-arm64-setup.exe` | the installer for ARM PCs (Snapdragon, Copilot+ PCs) |
| `VibeSalamander-0.9.2-portable-win-x64.zip` / `-portable-win-arm64.zip` | **portable**: unzip anywhere, nothing installed |
| `VibeSalamander-Git-plugin-0.9.2-win-x64.zip` / `-win-arm64.zip` | optional: the **Git** plugin (new) |

| `VibeSalamander-7-Zip-plugin-0.9.2-win-x64.zip` / `-win-arm64.zip` | optional: the 7-Zip plugin |

Have 0.8.0 or later? **Help → Check for Updates → Update now** installs this one (your settings stay). Not
code-signed yet: if SmartScreen warns, choose **More info → Run anyway**.

To add a plugin: unzip it, put its folder into `%AppData%\VibeSalamander\Plugins`, and start Vibe Salamander again.
The Git plugin needs Vibe Salamander 0.9.2 or later; Media Info works from 0.9.1 (its right-click entry from 0.9.2).

## New

- **Git plugin** (a separate download):
  - **In the panels:** the path line shows the branch with the commits to push and to pull (`main ↑2 ↓1`). Each
    file is colored by its Git state, and a **Git** column names it: Modified, Staged, New, Conflict, Ignored...
    This follows the repository as it changes, whichever program changed it.
  - **Changes:** stage, unstage, discard and commit (or amend), and compare a change in the file comparator.
  - **History:** the commits with a graph of branches and merges; what each commit changed, compared with the
    version before; **Blame**, who last changed each line; and **Browse This Version**, an old commit's whole tree
    in the panel, to look at and copy files out of with F5.
  - **Fetch, Pull, Push and Clone** run as jobs in the transfer panel, with Git's progress, and can be cancelled.
  - **Right-click menu:** a repository's folder, and the empty area or ".." in its top folder, have *Git ▸*
    Changes, History, Fetch, Pull and Push. A file in a repository has *Git ▸* History of This File and Blame.
  - **Safety:** repositories are read inside Vibe Salamander (by libgit2), so looking at a repository never runs
    its hooks or any program. Changes and server work run in your own Git for Windows, started by its full path,
    never a `git.exe` from the repository's folder.
- **Media Info plugin** (a separate download): the details of video, audio and picture files, as in the MediaInfo
  app, in a window (Basic or Complete; copy them, or save them as text, HTML, XML or JSON) and with F3.
  *Media Info...* is in the right-click menu of those files.
- **A copy in the same folder:** copying a file or folder onto itself (F5 with both panels in the same folder,
  Ctrl+C and Ctrl+V, or its own name typed in the copy dialog) makes "Name - Copy", then "Name - Copy (2)"..., as
  File Explorer does, instead of failing.
- **Plugins in the right-click menu:** a plugin's commands for a file or folder appear in its right-click menu; a
  plugin with several gathers them in a submenu named after it.

## For plugin authors

The contracts grew (older plugins keep loading):
- **panel decorators** (`IPluginPanelDecorator`): a status on the path line, item colors and a column of their own;
- `IPluginHost.CompareFiles` opens two files in the file comparator;
- `IPluginHost.RunJob` runs work as a job in the transfer panel, with progress and cancelling;
- a command's `AppliesTo` now also puts it in the right-click menu of folders, and of the panel's own folder.
