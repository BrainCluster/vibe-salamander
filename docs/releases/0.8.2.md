**Vibe Salamander 0.8.2**: Modern folder views by default, and First Steps sets them too.

## Download

| File | For |
|---|---|
| `VibeSalamander-0.8.2-win-x64-setup.exe` | **the installer**, most PCs (Intel / AMD, 64-bit) |
| `VibeSalamander-0.8.2-win-arm64-setup.exe` | the installer for ARM PCs (Snapdragon, Copilot+ PCs) |
| `VibeSalamander-0.8.2-win-x64.zip` / `-win-arm64.zip` | **portable**: unzip anywhere, nothing installed |
| `VibeSalamander-7-Zip-plugin-0.8.2-win-x64.zip` / `-win-arm64.zip` | optional: the 7-Zip plugin |

Have 0.8.0 or 0.8.1? **Help → Check for Updates → Update now** installs this one (your settings stay). Not
code-signed yet: if SmartScreen warns, choose **More info → Run anyway**.

## Better

- **Modern folder views are the default** for new settings (like File Explorer: This PC as tiles, folders of
  pictures and videos as thumbnails, a view remembered per folder). Existing settings keep their choice;
  Configuration → Views → Folder views switches.
- **Help → First Steps** now also chooses the folder views (Modern or Classic).
