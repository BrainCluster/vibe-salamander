**Vibe Salamander 0.8.1**: small fixes, and the first version 0.8.0 can update to by itself (Help → Check for Updates).

## Download

| File | For |
|---|---|
| `VibeSalamander-0.8.1-win-x64-setup.exe` | **the installer**, most PCs (Intel / AMD, 64-bit) |
| `VibeSalamander-0.8.1-win-arm64-setup.exe` | the installer for ARM PCs (Snapdragon, Copilot+ PCs) |
| `VibeSalamander-0.8.1-win-x64.zip` / `-win-arm64.zip` | **portable**: unzip anywhere, nothing installed |
| `VibeSalamander-7-Zip-plugin-0.8.1-win-x64.zip` / `-win-arm64.zip` | optional: the 7-Zip plugin |

Already have 0.8.0? **Help → Check for Updates → Update now** installs this one (the installed version with the new
installer, the portable one by replacing its files; your settings stay). Not code-signed yet: if SmartScreen warns,
choose **More info → Run anyway**.

## Better

- **Hot paths have their own button** at the end of each address bar (a star, next to the working directories): it
  opens the hot path list, as Shift+F9 does. They are no longer in the drive menu.
- **Help → Contents (F1)** opens the wiki.
