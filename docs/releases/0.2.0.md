**Vibe Salamander 0.2.0**: the Checksum plugin, live USB drives, a smoother and leaner file list, a smarter transfer panel and a tidier release folder.

## Download

| File | For |
|---|---|
| `VibeSalamander-0.2.0-win-x64.zip` | most PCs (Intel / AMD, 64-bit) |
| `VibeSalamander-0.2.0-win-arm64.zip` | ARM PCs (Snapdragon, Copilot+ PCs) |

Unzip anywhere and run **`VibeSalamander.exe` in the main folder**. No installation; .NET and the Windows App SDK are included.
Requires Windows 10 version 2004 or later, or Windows 11. Settings stay in `%AppData%\VibeSalamander`, so an existing
0.1.0 configuration carries over. Not code-signed yet: if SmartScreen warns, choose **More info → Run anyway**.

## New

**Checksum plugin** (a port of Open Salamander's)
- Calculate CRC32 (SFV), MD5, SHA-1, SHA-256 and SHA-512 of marked files and folders in a window that doesn't block the app
- Copy a checksum with a right-click (Ctrl+C / Ctrl+M / Ctrl+1 / Ctrl+2 / Ctrl+5), save SFV / MD5 / SHA files that other tools read
- Verify a checksum file with **Ctrl+Shift+V**: OK, Corrupted, Missing or Read error per file; Focus shows a file in the panel
- Choose which checksums to calculate (Configure...)

**Drives and files**
- Live USB drives: a plugged-in USB drive or memory card opens in the focused panel, and a panel showing a drive that is pulled out goes to This PC (Configuration → Drives)
- Context menu: **Run with PowerShell** for `.ps1`, **Run in cmd** for `.bat`, `.cmd` and Windows Script Host scripts

**Transfer panel**
- Closes by itself a few seconds after the last transfer (Configuration → Main Window, 0 = never); a thin accent bar shows the countdown
- The mouse over the panel or the focus in it holds the countdown; failed transfers stay in the panel
- Option to show the panel always (as a log) or only while transferring

**Other**
- Working directories history limit (Configuration → History, 10 by default)
- Help → Contents (F1) and the About dialog link to the Vibe Salamander repository

## Faster and leaner

- Big folders: Detailed rows have a fixed height, so the scrollbar stays steady when dragged through thousands of files; fewer rows are built ahead, and icons load after the texts and are skipped while scrolling fast
- Less memory: thumbnails within a memory budget and let go when scrolled away, memory given back after leaving a big folder, closing windows and minimizing; a leaner .NET memory mode
- Release builds are precompiled (ReadyToRun) for a quicker start and first use of each view
- Less work per navigation: the address bar keeps its buttons, and the folder watcher starts in the background

## Release folder

- The main folder now holds only `VibeSalamander.exe` (a small starter) and the documents; the program and its libraries are in `lib`
- Pinning the window to the taskbar pins the starter in the main folder
- `build\publish.ps1` builds the same folder locally
