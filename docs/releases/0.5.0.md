**Vibe Salamander 0.5.0**: Classic and Modern folder views, a 7-Zip plugin, Pack → Advanced, an error log, settings that survive damage, and many fixes found by new automatic UI tests.

## Download

| File | For |
|---|---|
| `VibeSalamander-0.5.0-win-x64.zip` | most PCs (Intel / AMD, 64-bit) |
| `VibeSalamander-0.5.0-win-arm64.zip` | ARM PCs (Snapdragon, Copilot+ PCs) |
| `VibeSalamander-7-Zip-plugin-0.5.0-win-x64.zip` / `-win-arm64.zip` | optional: the 7-Zip plugin |

Unzip anywhere and run **`VibeSalamander.exe` in the main folder**. No installation; .NET and the Windows App SDK are included.
Requires Windows 10 version 2004 or later, or Windows 11. Settings stay in `%AppData%\VibeSalamander`, so an existing
configuration carries over. Not code-signed yet: if SmartScreen warns, choose **More info → Run anyway**.

Also with Scoop: `scoop bucket add vibe-salamander https://github.com/BrainCluster/vibe-salamander`, then
`scoop install vibe-salamander`. New: a [wiki](https://github.com/BrainCluster/vibe-salamander/wiki) with a getting
started guide, all features and how to write plugins.

## New

**Classic and Modern views** (Configuration → Views → Folder views)
- **Classic** (the default): each panel keeps one view everywhere, like Salamander
- **Modern**, like File Explorer: This PC opens as tiles, folders of pictures and videos as thumbnails, and the view you choose for a folder is remembered for it

**7-Zip plugin** (a separate download, because it carries 7-Zip itself; an installed 7-Zip works too)
- Pack 7z with 7-Zip's settings: method, dictionary, word size, solid blocks, threads, encrypted file names, self-extracting archives
- Unpack, browse, test and change 7z; unpack CAB, WIM, MSI, CHM, ARJ, LZH, RPM, DEB, DMG and more
- To install: put the zip's `7-Zip` folder into `%AppData%\VibeSalamander\Plugins` and restart

**Pack → Advanced** (Alt+F5), from 7-Zip's *Add to Archive*: update modes (add, update, freshen, synchronize), path modes (relative, full, none), splitting into volumes, ZipCrypto for Windows Explorer, self-extracting .exe, NTFS times

**Archive plugins in the right-click menu**: an archive's menu has *Archives ▸* or *7-Zip ▸* with Unpack and the commands that fit it

**Error log** (Help → Error Log): errors are written to a daily log in `%LocalAppData%\VibeSalamander\Logs`; after a crash, the next start says so. Attach the log to a bug report: it says where the problem was.

**For plugin authors**: an example plugin, [`samples/HelloPlugin`](https://github.com/BrainCluster/vibe-salamander/tree/main/samples/HelloPlugin), and a [Writing plugins](https://github.com/BrainCluster/vibe-salamander/wiki/Writing-Plugins) guide

## Better

- **Settings survive damage**: a settings file that can't be read is kept as `settings.broken-<date>.json`, everything readable is still used, and you're told
- **Narrow panels keep the names visible**: columns step aside (Attributes, Time, Date, Extension, Size) instead of squeezing the names
- **Sort by size** puts the largest files first
- Thumbnails: leaving the view gives the pictures' memory back; the size slider snaps to steps of 32 pixels
- The transfer panel closes 2 seconds after the last transfer (was 3)
- Find and plugin windows stay in front of the main window
- File operations: many edge cases handled and tested (links and junctions are never followed into loops or deleted through, read-only and hidden targets, files in the way of folders, renaming only the case of a name)
- Change Case and Change Attributes stay inside the selection

## Fixed

- The transfer panel counted each finished file twice ("5.72 MB / 2.86 MB")
- The Time column cut off "PM"
- Shift+F10 (the context menu from the keyboard) unmarked the files
- The Pack dialog scrolls when the 7z options are taller than the window
- The starter finds the program also when it's started through a link (as Scoop and winget do)
