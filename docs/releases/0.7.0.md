**Vibe Salamander 0.7.0**: a much stronger Find, Find Duplicates, Compare Files and directory Synchronize, a smarter copy queue with speed limits and graphs, multi-rename, quick view, and Total Commander's shortcuts as an option.

## Download

| File | For |
|---|---|
| `VibeSalamander-0.7.0-win-x64.zip` | most PCs (Intel / AMD, 64-bit) |
| `VibeSalamander-0.7.0-win-arm64.zip` | ARM PCs (Snapdragon, Copilot+ PCs) |
| `VibeSalamander-7-Zip-plugin-0.7.0-win-x64.zip` / `-win-arm64.zip` | optional: the 7-Zip plugin |

Unzip anywhere and run **`VibeSalamander.exe` in the main folder**. No installation; .NET and the Windows App SDK are included.
Requires Windows 10 version 2004 or later, or Windows 11. The editor, Compare Files and the rendered previews use the
Microsoft Edge WebView2 Runtime, which Windows 11 and up-to-date Windows 10 already have. Settings stay in
`%AppData%\VibeSalamander`, so an existing configuration carries over. **New: portable mode** — put an empty
`portable.flag` file next to `VibeSalamander.exe` and everything is kept in a `Data` folder beside it.
Not code-signed yet: if SmartScreen warns, choose **More info → Run anyway**.

Also with Scoop: `scoop bucket add vibe-salamander https://github.com/BrainCluster/vibe-salamander`, then
`scoop update vibe-salamander` (or `scoop install vibe-salamander`).

## New

**Find and compare**
- **Find files (Alt+F7)**: several text rows, each "contains" or "doesn't contain" (text, regular expression or hex bytes; all or any), size, dates, attributes, depth, folders to skip, inside ZIP files; the matching line shown with each result; saved searches; **Show in Panel** to copy, move or delete the results like any files
- **Find duplicates (Alt+Shift+F7)** by content, name or size, reading most files only a little; select all but the newest (or oldest) of each group in one click
- **Compare directories (Ctrl+F10)** by date, size, attributes or content, with a list of the differences to filter and **synchronize**: left → right, right → left, both ways, optionally as a mirror
- **Compare files (Ctrl+Shift+C)**: side by side or inline in Visual Studio Code's diff editor, changes highlighted to the character, copied across with Alt+→ / Alt+←, both sides editable and saved safely; **only the differences** folds the rest away; binary files byte by byte

**Copying**
- **Speed limits** per transfer and for all of them, changed while copying; **speed graphs** in the transfer panel
- **One transfer per disk** (copies between different disks still run together); reorder the queue, start one next
- **Checks before copying**: free space, files too big for FAT32, write-protected drives — said before anything is copied
- **Verify copies** (optional): every copy read back and compared
- A locked file says **which program** holds it
- **When done**: close, lock, sleep, hibernate or shut down after the last transfer (with a 60-second countdown); progress on the taskbar button
- The "file exists" question shows both files side by side, which one is newer or larger, and a Compare button
- **Duplicate** (Alt+Shift+D): a copy next to the original, named in place

**Files and panels**
- **Multi-rename** (Shift+F2): masks (`[N]`, `[N1-3]`, `[E]`, `[C]`, `[P]`, `[YMD]`, `[hms]`), search and replace with regular expressions, case, counter; every new name previewed with its problems before anything happens
- **Quick view** (Ctrl+Q): the other panel shows the file under the cursor
- **All files of the subfolders** (Ctrl+B) in one list
- **Hot path list** (Shift+F9); the name or path under the cursor into the command line (Ctrl+Enter, Ctrl+Shift+Enter); the command line's history (Alt+F8)
- **Total Commander's shortcuts** as an option (Configuration → Keyboard → Shortcuts like): F2 refresh, Shift+F6 rename, Ctrl+M multi-rename, Ctrl+Q quick view, Ctrl+B, Ctrl+D and more; the menus and the F-key bar follow
- The keyboard page tells **which command a key has** and prints a **cheat sheet**
- Starting with folders: `-L folder -R folder -A folder -P 1|2`; with one instance, a second start hands them over

**Viewer and editor**
- Pictures: zoom to 6400 %, fit the width (W), mirror (M), full screen (F11), the next pictures decoded ahead; more details (rating, keywords, author, copyright, color profile, altitude) and **Show on map**
- Editor: **Minify** and **Sort keys** for JSON (Minify for XML too), comment a line (Ctrl+/), a live preview for SVG

**Looks and settings**
- New color schemes: Solarized and GitHub (dark and light), Altap Salamander classic; **import a Visual Studio Code theme**
- Dates as 2026-10-28, times in 24 or 12 hours
- **Help → First Steps**: shortcuts, theme, colors and language on one page

## Better

- Find, Duplicates, Compare and Synchronize name their buttons for screen readers; Compare Files announces "Difference 2 of 5"
- Synchronize is ready as soon as a comparison ends
- After Format, Minify, Sort keys, Find or Go to line in the editor, the keyboard is back in the text (Ctrl+S right after them saved nothing)
- Compare Files shows the number of differences in its title, so it's on the taskbar too
- Many more automatic tests, also of the user interface: search, duplicates, synchronizing, speed limits, Compare Files, multi-rename, quick view and the new keys are tried at every change
