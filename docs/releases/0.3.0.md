**Vibe Salamander 0.3.0**: FTP and SFTP servers in the panels, password-protected ZIPs, archives you can change in place, a better Find window and many smaller fixes.

## Download

| File | For |
|---|---|
| `VibeSalamander-0.3.0-win-x64.zip` | most PCs (Intel / AMD, 64-bit) |
| `VibeSalamander-0.3.0-win-arm64.zip` | ARM PCs (Snapdragon, Copilot+ PCs) |

Unzip anywhere and run **`VibeSalamander.exe` in the main folder**. No installation; .NET and the Windows App SDK are included.
Requires Windows 10 version 2004 or later, or Windows 11. Settings stay in `%AppData%\VibeSalamander`, so an existing
configuration carries over. Not code-signed yet: if SmartScreen warns, choose **More info → Run anyway**.

## New

**FTP / SFTP plugin** (first version)
- Commands → **Connect to FTP / SFTP Server**: saved servers (SFTP, FTP, FTPS explicit / implicit), password or SSH key file
- Saved passwords are encrypted for your Windows account; SFTP host keys and untrusted TLS certificates are asked about once and remembered, and a changed key warns
- The server opens in the panel like a folder, with its own address bar and folder menus; `..` at the root goes back to This PC
- F5 / F6 copy or move to the other panel, F5 / F6, drag and drop or Ctrl+V upload from a disk panel, F8 deletes, F7 creates a directory, F2 renames, Enter / F3 / F4 open a temporary copy
- Transfers run in the transfer panel with progress, pause, cancel and the usual overwrite / skip / keep both questions

**Archives**
- Pack (Alt+F5): **encrypt ZIPs with a password** (AES-256, typed twice, never saved)
- **Change ZIP, TAR and TAR.GZ archives in place**: copy or drop files in, delete them (F8), move them out (F6); files added to an encrypted ZIP get its password. 7-Zip and RAR stay read-only
- The archive is rewritten next to the old one and replaces it only when everything went well

**Find Files and Directories**
- Sort the results by clicking a column header (again for the other direction), also while searching
- Resize the columns at the header (double-click a grip for the default width); the widths are remembered
- Right-click a result for the Vibe context menu: Open, **Open file location** (in the focused panel), Open with, View, Edit, Cut, Copy, **Copy file path**, Delete, Properties and the Windows menu

## Better

- Thumbnails load much faster when scrolling through thousands of images: rows scrolled away are skipped, Windows' own thumbnail cache is used first, and pictures are prepared off the UI thread
- Typing the same letter again (A, A, A) steps through the items starting with it, like Explorer
- After a delete or refresh the panel keeps its scroll position instead of the focused row jumping to the bottom
- Dragging files starts also when the mouse is already moving at the click
- New README screenshot
