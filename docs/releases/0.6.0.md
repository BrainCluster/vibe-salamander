**Vibe Salamander 0.6.0**: a built-in viewer (F3) for any file and a built-in editor (F4) with the editor of Visual Studio Code.

## Download

| File | For |
|---|---|
| `VibeSalamander-0.6.0-win-x64.zip` | most PCs (Intel / AMD, 64-bit) |
| `VibeSalamander-0.6.0-win-arm64.zip` | ARM PCs (Snapdragon, Copilot+ PCs) |
| `VibeSalamander-7-Zip-plugin-0.6.0-win-x64.zip` / `-win-arm64.zip` | optional: the 7-Zip plugin |

Unzip anywhere and run **`VibeSalamander.exe` in the main folder**. No installation; .NET and the Windows App SDK are included.
Requires Windows 10 version 2004 or later, or Windows 11. The editor and the rendered previews use the Microsoft Edge
WebView2 Runtime, which Windows 11 and up-to-date Windows 10 already have. Settings stay in `%AppData%\VibeSalamander`,
so an existing configuration carries over. Not code-signed yet: if SmartScreen warns, choose **More info → Run anyway**.

Also with Scoop: `scoop bucket add vibe-salamander https://github.com/BrainCluster/vibe-salamander`, then
`scoop update vibe-salamander` (or `scoop install vibe-salamander`).

## New

**The viewer (F3)** opens any file, whatever its size
- **Text and hex** for files of any size: a multi-gigabyte log opens at once and is indexed while you read
- Encodings detected (UTF-8 / UTF-16, ANSI, OEM and more) and switchable; find text, whole words, regular expressions or hex bytes (Ctrl+F, F3 / Shift+F3); go to a line or an offset (Ctrl+G); wrap (W); line numbers
- **JSON, XML and YAML as a tree**; a broken file says where the problem is
- **Markdown, Jupyter notebooks and web pages rendered**: tables, task lists, code, pictures next to the file, notebook outputs. Nothing is loaded from the internet and no script runs unless you allow it
- **Pictures**: JPEG, PNG, GIF, WebP, HEIC, AVIF, JPEG XL, SVG and camera RAW (with Windows' free extensions); the mouse wheel zooms around the pointer, a zoomed picture is dragged with the mouse, R rotates; details beside it (size, camera, lens, exposure, date taken, location)
- **PDFs** page by page, **audio and video** with their details
- Ctrl+PgUp / Ctrl+PgDn (← / → for pictures) go to the previous or next file of the folder; Ctrl+1…7 switch between the views a file has; F4 edits it

**The editor (F4)**: Monaco, the editor of Visual Studio Code
- Syntax colors for more than 70 languages, folding, multiple cursors, the minimap, the command palette (F1)
- **JSON, XML and YAML checked while you type**: problems underlined, the first one in the status line; Format (Shift+Alt+F) tidies JSON and XML
- **A live preview** of Markdown and HTML beside the text (Ctrl+Shift+V)
- Find and replace with regular expressions, go to line
- The encoding and line endings are kept, or chosen when saving; characters the encoding can't hold are pointed out
- **Safe saving**: written next to the original and swapped in only when complete, with an optional backup (.bak); changes made by another program are noticed; closing never loses unsaved work silently
- **Files in ZIP and TAR archives and on FTP / SFTP servers** are edited too: each save puts them back

**Configuration → Viewers / Editors**: switch the built-in viewer or editor off (files then open in their Windows apps, as before), and their options: wrap, line numbers, font size, picture details, internet content and scripts in pages, minimap, preview, backup. Your own viewers and editors per file mask still come first.

## Better

- Big parts of the main window's code moved into smaller, tested pieces (no change you should notice, except fewer surprises)
- More automatic UI tests: the viewer and the editor are tried on a file of each kind at every change
