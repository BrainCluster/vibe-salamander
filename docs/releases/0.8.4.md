**Vibe Salamander 0.8.4**: new address bar buttons, list menus of one size, a grouped drive bar, and an About page in the configuration.

## Download

| File | For |
|---|---|
| `VibeSalamander-0.8.4-win-x64-setup.exe` | **the installer**, most PCs (Intel / AMD, 64-bit) |
| `VibeSalamander-0.8.4-win-arm64-setup.exe` | the installer for ARM PCs (Snapdragon, Copilot+ PCs) |
| `VibeSalamander-0.8.4-portable-win-x64.zip` / `-portable-win-arm64.zip` | **portable**: unzip anywhere, nothing installed |
| `VibeSalamander-7-Zip-plugin-0.8.4-win-x64.zip` / `-win-arm64.zip` | optional: the 7-Zip plugin |

Have 0.8.0 or later? **Help → Check for Updates → Update now** installs this one (your settings stay). Not
code-signed yet: if SmartScreen warns, choose **More info → Run anyway**.

## New

- **Address bar buttons** for the **command line history** (Alt+F8, next to the hot paths) and the **opened
  files** (Alt+F11, next to the working directories); each menu opens under its button
- **Configuration → History → Opened files to keep** (10 by default)
- **Configuration → About**, at the bottom of the pages: Help → About's content, and **Check for Updates** with the
  answer right there
- **Configuration → Change Drive Menu** can add any folder of Commands → Open Folder to the drive menu (Desktop,
  Downloads, Recycle Bin, ...)

## Better

- **List menus** (drives, hot paths, opened files, working directories, histories, user menu) all have the same
  width, a title, and up to 10 rows, scrolling beyond; a long path slides sideways under the mouse or the keyboard
  and shows all of itself as a tooltip; a letter jumps to the next row starting with it
- **The portable zips say so in their names**: `...-portable-win-x64.zip`, `...-portable-win-arm64.zip`
- **The drive menu** is compact (25 characters) with each drive's free space at the right
- **The drive bar and the drive menu** are grouped (disks, removable and CD/DVD drives, network drives) with
  separators between the groups, and use the same icons for the kinds of drives
