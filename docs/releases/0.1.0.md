The first release of **Vibe Salamander**, a fast, keyboard-first dual-pane file manager for Windows,
a modern spiritual successor to [Open Salamander](https://github.com/OpenSalamander/salamander).

## Download

| File | For |
|---|---|
| `VibeSalamander-0.1.0-win-x64.zip` | most PCs (Intel / AMD, 64-bit) |
| `VibeSalamander-0.1.0-win-arm64.zip` | ARM PCs (Snapdragon, Copilot+ PCs) |

Unzip anywhere and run `VibeSalamander.exe`. No installation and no .NET or Windows App SDK download
needed, everything is included. Requires Windows 10 version 2004 or later, or Windows 11.
Settings are kept in `%AppData%\VibeSalamander`.

The program isn't code-signed yet, so Windows SmartScreen may warn the first time:
choose **More info → Run anyway**.

## What's in 0.1.0

**Panels and navigation**
- Two panels with Open Salamander's keyboard model and menus (Left, Files, Edit, Commands, Plugins, Options, Right, Help)
- Brief, Detailed, Icons, Thumbnails and Tiles views; column chooser and resizing; sorting by name, extension, date, size, attributes
- Windows 11 style address bar: drive drop-down, clickable segments, subfolder chevrons, type a path; drive bars and This PC with free space
- Quick search by typing, marking with Insert / Space / Shift, mouse rectangle selection, selection by mask, save / restore selections
- Hot paths 1–9, back / forward, working directories, filter, hidden files toggle, maximize and swap panels, auto-refresh

**Files**
- Own copy / move / delete engine in a background transfer panel: queue, parallel transfers, pause / resume / cancel
- In-place rename (F2 or slow click on the name), new folders and files created and renamed in place
- Change attributes and case, NTFS compression / encryption, properties, security, email, shortcuts, clipboard, drag & drop with Explorer
- Files open in their default Windows apps; Open with; viewers and editors by file mask
- Vibe context menu with the most useful commands, and the full Windows context menu at its bottom
- Fewer dialogs: notifications that close themselves instead of message boxes

**Archives and disk images**
- Plugin system with Plugins Manager and a Plugins menu
- Archive plugin: pack ZIP / TAR / TAR.GZ (Alt+F5); unpack ZIP, 7z, RAR, TAR, gz, bz2, xz, lz (Alt+F6) with passwords
- Browse archives like folders, copy files out, open files inside them
- Mount .iso / .img / .vhd / .vhdx images (the drive opens in the other panel) and unmount them

**Tools**
- Find files, compare directories, directory sizes, drive information, file lists
- Command line, command shell, user menu with variables, network drives and shares, special folders

**Configuration**
- Configuration window with the Open Salamander pages: General, Recycle Bin, Confirmations, Panels, Views, Appearance, Colors, Main Window, Drives, Change Drive Menu, Viewers, Editors, History, Keyboard, Toolbar, Hot Paths, User Menu, Plugins
- Color schemes: Vibe, Explorer, Yazi, Superfile, Tokyo Night, Gruvbox, Dracula, Nord, Phosphor, Norton Commander, DOS Navigator, Custom; highlighting by file mask
- Every shortcut can be changed; customizable toolbar; export / import of settings
- Light / dark / system theme, Compact / Comfortable density, panel font
- 12 languages: English, Hrvatski, Čeština, Deutsch, Español, Français, Italiano, Nederlands, Polski, Português (Brasil), Русский, Українська

## Known limitations

- Archives are read-only in the panels (no copying into or deleting inside an archive yet)
- No FTP / SFTP yet; Convert (Ctrl+K) and Last command (Ctrl+I) are not implemented
- First release: expect rough edges, and please report problems in Issues
