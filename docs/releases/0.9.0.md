**Vibe Salamander 0.9.0**: continue as administrator in protected folders, and see at a glance which files are only in the cloud.

## New

- **Continue as administrator.** Copying, moving or deleting in a protected folder such as `Program Files` or
  `Windows` used to end with "Access is denied". The error question now offers **Continue as administrator**:
  Windows asks once, and the rest of that copy, move or delete goes through without asking again. Renaming (F2), a
  new folder (F7), Change Attributes and Change Case offer it too. If you say no in Windows' prompt, you get the
  usual error.
  Vibe Salamander itself never runs as administrator: a small helper (`VibeSalamander.Elevated.exe`, in the `lib`
  folder) starts for that one operation, accepts work only from the Vibe Salamander that started it, and ends with
  the operation.
- **Cloud files are marked in the panel.** A file that is only in the cloud (OneDrive, iCloud, Dropbox) has a small
  cloud over its icon, and a file always kept on this device has a green check, as in Explorer.

## Fixed

- **FTP / SFTP**: opening the connections window with no saved servers didn't show the New Server form.
- **Checksums** shows its progress bar while it reads the folders.

## Under the hood

- Copying onto a disk that fills up is tested on a small virtual disk: nothing half-copied is left, the files that
  fit arrive, and a move keeps the file that didn't fit.
- The UI tests wait for what each step needs (a dialog, a transfer, a tool window, a picture) instead of fixed pauses.
- The release notes now show the measured speed next to the previous release's (from the next release on).
