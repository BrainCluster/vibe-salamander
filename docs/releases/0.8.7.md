**Vibe Salamander 0.8.7**: Run as administrator in the right-click menu.

## Download

| File | For |
|---|---|
| `VibeSalamander-0.8.7-win-x64-setup.exe` | **the installer**, most PCs (Intel / AMD, 64-bit) |
| `VibeSalamander-0.8.7-win-arm64-setup.exe` | the installer for ARM PCs (Snapdragon, Copilot+ PCs) |
| `VibeSalamander-0.8.7-portable-win-x64.zip` / `-portable-win-arm64.zip` | **portable**: unzip anywhere, nothing installed |
| `VibeSalamander-7-Zip-plugin-0.8.7-win-x64.zip` / `-win-arm64.zip` | optional: the 7-Zip plugin |

Have 0.8.0 or later? **Help → Check for Updates → Update now** installs this one (your settings stay). Not
code-signed yet: if SmartScreen warns, choose **More info → Run anyway**.

## New

- **Run as administrator** in the right-click menu of programs (.exe), installers (.msi), scripts (.bat, .cmd,
  .ps1, .vbs), consoles (.msc), Control Panel items and shortcuts. Windows asks first, as in Explorer; scripts run in
  their own folder, in a window that stays open. Also a command for a shortcut of your own (Configuration →
  Keyboard) or the toolbar.
