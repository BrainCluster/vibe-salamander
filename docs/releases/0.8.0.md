**Vibe Salamander 0.8.0**: an installer, portable zips, and updates from inside the program (Help → Check for Updates).

## Download

| File | For |
|---|---|
| `VibeSalamander-0.8.0-win-x64-setup.exe` | **the installer**, most PCs (Intel / AMD, 64-bit) |
| `VibeSalamander-0.8.0-win-arm64-setup.exe` | the installer for ARM PCs (Snapdragon, Copilot+ PCs) |
| `VibeSalamander-0.8.0-win-x64.zip` / `-win-arm64.zip` | **portable**: unzip anywhere, nothing installed |
| `VibeSalamander-7-Zip-plugin-0.8.0-win-x64.zip` / `-win-arm64.zip` | optional: the 7-Zip plugin |

**Installer:** run it. *For me only* installs into `%LocalAppData%\Programs\Vibe Salamander` without administrator
rights; *for all users* into Program Files. Start menu entry, optional desktop icon, uninstaller (Windows Settings →
Apps). Settings stay in `%AppData%\VibeSalamander`, so an existing configuration carries over.

**Portable zip:** unzip anywhere and run **`VibeSalamander.exe` in the main folder**. The zip now keeps everything in
a `Data` folder beside the program (its `portable.flag` does that); the first start copies the settings you had in
`%AppData%` into it. Delete `portable.flag` to keep using `%AppData%` instead.

Requires Windows 10 version 2004 or later, or Windows 11; .NET and the Windows App SDK are included. Not code-signed
yet: if SmartScreen warns, choose **More info → Run anyway**.

Also with Scoop: `scoop update vibe-salamander` (Scoop installs the portable zip and keeps its `Data` folder between
updates).

## New

**Updates from inside the program**
- **Help → Check for Updates** asks GitHub for the newest version; by default also once a day (Configuration →
  General → *Check for updates once a day*; nothing but that question is sent)
- A new version shows what's new, then **Update now**, **Skip this version** or **Later**
- **Installed**: the new installer is downloaded and runs silently over the old version, then Vibe Salamander starts again
- **Portable**: the new zip is downloaded; once the program has closed its files are replaced (your `Data` stays) and it starts again
- Every download is checked against its size and the SHA-256 GitHub gives for it; running transfers and open editors are finished first

**An installer** (Inno Setup) for x64 and ARM64: per user without administrator rights, or for all users

**Portable zips**: settings, plugins and logs in a `Data` folder beside the program

## Better

- **The Commands and Files menus are grouped** into submenus: Find, Compare, Sizes and Drives, Lists, Network; Rename, Attributes and Security, Archives
- **The picture viewer** opens every picture fitted to the window (at 100 % when it's smaller), not at the previous picture's zoom
- winget versions from now on install with the installer (for the user or for the machine)

From this version on, Vibe Salamander updates itself: 0.7.0 doesn't have the update check yet, so this one update is
by hand (run the installer, or unzip the new zip).
