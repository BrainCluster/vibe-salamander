**Vibe Salamander 0.8.6**: icon packs, Windows' icons that stay put, and no more focus rectangles around list rows.

## Download

| File | For |
|---|---|
| `VibeSalamander-0.8.6-win-x64-setup.exe` | **the installer**, most PCs (Intel / AMD, 64-bit) |
| `VibeSalamander-0.8.6-win-arm64-setup.exe` | the installer for ARM PCs (Snapdragon, Copilot+ PCs) |
| `VibeSalamander-0.8.6-portable-win-x64.zip` / `-portable-win-arm64.zip` | **portable**: unzip anywhere, nothing installed |
| `VibeSalamander-7-Zip-plugin-0.8.6-win-x64.zip` / `-win-arm64.zip` | optional: the 7-Zip plugin |

Have 0.8.0 or later? **Help → Check for Updates → Update now** installs this one (your settings stay). Not
code-signed yet: if SmartScreen warns, choose **More info → Run anyway**.

## New

- **Icon packs** (Configuration → Appearance → Icons): Windows' own icons like File Explorer, or Vibe Salamander's
  icons by kind of file (pictures, videos, music, archives, code, documents, spreadsheets, PDFs, programs, ...), in
  color or in one color
- **The hot paths menu** has **Configure...** at the bottom (Configuration → Hot Paths)

## Better

- **Windows' icons are consistent**: folders no longer turn into hollow outlines (the icons are read the way
  Windows requires), nothing else flashes while they load, and drives with simple icons, archives and servers show
  the file type's Windows icon
- **No white focus rectangle** around rows of the panels, the list menus (drives, opened files, hot paths, ...),
  Find, transfers, compare, the configuration's lists and the viewer's trees: the highlight shows where you are
